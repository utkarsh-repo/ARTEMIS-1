# ARTEMIS Granular Requirements Register

This is the implementation-level register. `VERIFIED` means the listed acceptance criteria were exercised by tests in the current repository; `IMPLEMENTED` is not considered verified. The reference audit is source-backed but not yet exhaustive: upstream network access is available through the GitHub source connector, while direct `git clone` is unavailable in this environment. No upstream source code has been copied into ARTEMIS.

**Status vocabulary:** `NOT_STARTED`, `IN_PROGRESS`, `BLOCKED`, `IMPLEMENTED`, `VERIFIED`.

**Reference baseline inspected:** Cairn README and dispatcher/server protocol specifications; ARTEX README plus selected planner, worker, finding workflow, capture, database, server/orchestration, and UI type files. References: [Cairn](https://github.com/oritera/Cairn), [Cairn dispatcher design](https://github.com/oritera/Cairn/blob/main/docs/specs/dispatcher-design.md), [Cairn server protocol](https://github.com/oritera/Cairn/blob/main/docs/specs/server-protocol.md), [ARTEX](https://github.com/trhhubsd/ARTEX).
